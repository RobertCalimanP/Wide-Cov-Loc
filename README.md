# 🌍 Wide Coverage

Este é um projeto de **landing page responsiva** desenvolvido como parte dos meus estudos em **HTML** e **CSS**.  
A página apresenta uma proposta de serviço de caronas com ampla cobertura geográfica.

![Screenshot do Projeto](img/img%20projeto%20um.png)

---

## 📄 Sobre o projeto

A **Wide Coverage** é uma página estática com foco em **design moderno** e **boas práticas de front-end**.  
O projeto foi construído com:

- HTML5 semântico
- Estilização completa com CSS3
- Layout responsivo com media queries
- Tipografia personalizada com Google Fonts (Poppins e Montserrat)
- Estrutura visual organizada e com espaçamento proporcional

---

## 🖌️ Principais estilos aplicados

- Reset global com `box-sizing: border-box` e margens zeradas
- Layout fluido para telas menores usando `@media screen and (max-width: 900px)`
- Estilo visual consistente com uso de `letter-spacing`, `font-weight` e `line-height`
- Botões estilizados com `border-radius` e contraste de cores
- Ocultação e reorganização de elementos no mobile para melhor usabilidade

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts
